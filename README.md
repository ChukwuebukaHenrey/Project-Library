# My Library 📚

A simple, interactive library app built with HTML, CSS, and JavaScript. My Library allows users to organize a collection of books, keep track of their reading progress, and search for books in their library.

🔗 **Live Demo:** [My Library](https://chukwuebukahenrey.github.io/Project-Library/)

## Preview

![My Library application screenshot](images/Twilight%20Meadow%20Overlooking%20the%20City.png)

## Features

- **Add Books:** Add books to your library by entering the title, author, number of pages, and reading status.
- **Track Reading Progress:** Toggle a book's read status to keep track of which books you have finished.
- **Remove Books:** Remove books from your library when they are no longer needed.
- **Search Library:** Search for books by title using the search field.
- **Responsive Layout:** A CSS Grid layout adapts to different screen widths.
- **Glassmorphism UI:** A modern interface featuring translucent cards, blurred backgrounds, subtle borders, and shadows.
- **Form Validation:** Required fields help prevent incomplete book entries.

## Built With

- **HTML5** — Page structure, forms, and semantic elements.
- **CSS3** — Responsive layouts, CSS Grid, Flexbox, custom properties, transitions, and glassmorphism effects.
- **JavaScript (Vanilla)** — Book objects, event handling, search functionality, and dynamic rendering.
- **Google Fonts / Custom Fonts** — Custom typography using the Alan Sans font files included in the project.
- **GitHub Pages** — Hosting and deployment.

## Getting Started

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/chukwuebukahenrey/Project-Library.git
   ```

2. Navigate into the project directory:

   ```bash
   cd Project-Library
   ```

3. Open `index.html` in your browser, or use the **Live Server** extension in Visual Studio Code.

No build tools or package installation are required.
